# PlaneSlate catalogs and liveries

Published catalogs, aircraft artwork and airline logos for PlaneSlate Micro
(`micro_360`) and Mini (`mini_800`).

[Browse the library](https://planeslate.com/liveries.html) ·
[Releases](https://github.com/PlaneSlate/liveries/releases) ·
[Credits](https://github.com/PlaneSlate/firmware/blob/main/CREDITS.md) ·
[Third-party notices](https://github.com/PlaneSlate/firmware/blob/main/THIRD_PARTY_NOTICES.md)

## Install and update

Use the device's content-update function or the
[Web Installer](https://planeslate.com/installer/). Current common content
releases contain coordinated catalog, registration, livery and logo data with
separate Micro and Mini packages. Firmware and content versions are independent.
Older livery-only releases remain historical downloads.

Packages are checked for product identity, integrity and version consistency.
Do not combine partial files from different generations. Use the installer or
supported device recovery tools for a first installation.
